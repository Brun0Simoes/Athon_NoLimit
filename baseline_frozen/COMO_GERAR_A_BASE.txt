BASE O09M-CLIP - como gerar os três arquivos usados pelos modelos
=================================================================

A base P usa só os arquivos oficiais da competição, o GEFSv12 (NOAA) e o CFSv2 NMME (IRI).
Ela gera:
  data/submissions/official_O09M-CLIP_20260919T155410949985Z.csv   (previsão da base, 2023-2024)
  final_search/runs/base_residual.npz                              (base fora da amostra, 2010-2019)
  data/experiments/o09m/transport_oof.npz                          (base fora da amostra, 2020-11 a 2022-12)

Ambiente: Python 3.12 com uv (uv sync nesta pasta). Os scripts de GEFS leem GRIB e precisam de um
Python com eccodes. Coloque os arquivos oficiais em
dataset_oficial/previsao-climatica-de-precipitacao-sobre-a-america-do-sul/.
Rode nesta pasta, na ordem (os argumentos de cada script estão no cabeçalho dele):

  1. GEFSv12 (https://noaa-gefs-retrospective.s3.amazonaws.com e https://noaa-gefs-pds.s3.amazonaws.com)
       python scripts/fetch_gefs_reforecast.py
       python scripts/fetch_gefs_janelas.py --todos
       python scripts/fetch_gefs_operacional_quarta.py 2020-11 2020-12 ... 2022-12
       python scripts/download_gefs_submission.py
  2. CFSv2 NMME (https://iridl.ldeo.columbia.edu/SOURCES/.Models/.NMME/.NCEP-CFSv2/)
       python scripts/fetch_nmme_cfsv2.py
       python scripts/ingest_cfsv2.py
  3. Base O-02 (membros oficiais + CFSv2)
       python scripts/official_v4o_dyn.py --stage validate
       python scripts/official_v4o_dyn.py --stage final
  4. Correção GEFS calibrada
       python scripts/o09m_cal.py --stage all
  5. python scripts/o09m_transport_oof.py
  6. python scripts/o09m_clip.py
  7. python scripts/o09m_submission.py --stage generate --arm O09M-CAL
  8. python scripts/o09m_clip_submission.py
  9. python -m final_search.engine.base_residual

Os scripts conferem os pré-registros em data/frozen/ e os documentos em docs/; não altere esses arquivos.
